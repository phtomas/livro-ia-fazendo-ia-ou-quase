Capítulo 13 · Laboratório LAB-13A

Comparar arquivos sem pedir opinião à IA

Um procedimento determinístico, com critérios para saber quando o resultado é PASS.

Roteiro disponível para reprodução. A validação final depende da execução no ambiente do leitor. Atualização editorial: 14/11/2026.

Objetivo

Comparar dois arquivos reais por tamanho e hash SHA-256, sem uma chamada de modelo de linguagem.

Requisitos

Python 3.9 ou superior, terminal Windows/PowerShell ou Linux/macOS e dois arquivos fictícios.

Preparação

Crie laboratorio-ia/entrada/original.txt e laboratorio-ia/entrada/copia.txt com o mesmo conteúdo. Salve comparar_arquivos.py na raiz de laboratorio-ia.

Windows / PowerShell

py comparar_arquivos.py entrada/original.txt entrada/copia.txt

Linux / macOS

python3 comparar_arquivos.py entrada/original.txt entrada/copia.txt

Conferência

  • Arquivos idênticos: PASS: arquivos identicos, código 0.
  • Arquivos diferentes: FAIL: arquivos diferentes, código 1.
  • Arquivo ausente: ERRO, código 2.

Altere um dos arquivos e execute de novo. Guarde a saída e a data em evidencias. Se Python não for encontrado, confira sua instalação e o comando utilizado.

Atenção: use apenas cópias fictícias. Um hash não substitui uma revisão completa em cenários adversariais. Nenhuma credencial é necessária neste exercício.
