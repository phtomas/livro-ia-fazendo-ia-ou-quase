A ferramenta que não precisa de opinião

Dois arquivos, três estados de saída e um teste que não precisa de conversa.

CAPÍTULO 13
LAB-13A

Estado: roteiro publicado.
ROTEIRO PUBLICADO · 14/11/2026O leitor deverá reproduzir o teste no próprio ambiente. O texto abaixo não representa uma execução em seu computador.

Objetivo

Verificar se dois arquivos têm o mesmo conteúdo por meio de tamanho e hash SHA-256. O cálculo é determinístico; não depende de um modelo de IA.

Requisitos

Python 3.9 ou superior, terminal Windows (PowerShell) ou Linux/macOS, arquivos descartáveis. Nenhuma chave de API.

Preparação

  1. Crie a pasta laboratorio-ia com as subpastas entrada e evidencias.
  2. Escreva a mesma frase em entrada/original.txt e entrada/copia.txt.
  3. Salve comparar_arquivos.py na pasta principal do laboratório.

Execução

Windows / PowerShell

py comparar_arquivos.py entrada/original.txt entrada/copia.txt

Linux / macOS

python3 comparar_arquivos.py entrada/original.txt entrada/copia.txt

Critérios de prova

  1. Conteúdo idêntico: PASS: arquivos identicos, código de saída 0.
  2. Modifique apenas um arquivo: FAIL: arquivos diferentes, código 1.
  3. Remova um dos arquivos: ERRO:, código 2.

Para inspecionar o código de saída use $LASTEXITCODE no PowerShell ou echo $? em Linux/macOS, imediatamente depois do comando. Registre a saída e a versão do Python na pasta evidencias.

LIMITAÇÃO ASSUMIDAHashes não identificam autoria, intenção nem ordem das modificações. Em situações adversariais, complemente com comparação byte a byte. O script não altera ou apaga os arquivos.
