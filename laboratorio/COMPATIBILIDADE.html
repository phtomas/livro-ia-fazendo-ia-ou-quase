QUAL COMANDO USAR?Se você baixou o ZIP público, use executar.py no diretório raiz extraído. Os comandos que aparecem dentro do texto do livro podem pressupor a árvore Quarto privada e, portanto, não funcionam literalmente nesse ZIP.

Um comando para cada capítulo

python laboratorio/kit-do-leitor/executar.py --listar
python laboratorio/kit-do-leitor/executar.py --capitulo 13 --saida ../ensaio-13
python laboratorio/kit-do-leitor/executar.py --todos --saida ../ensaios-21

No Windows, py pode substituir python, se configurado. Use Python 3.11+. A pasta de saída deve ser nova e externa ao repositório. Baixe o projeto pelo botão Code → Download ZIP do GitHub público; não é necessário instalar Git.

Por que os caminhos são diferentes?

Dentro do livro, alguns exemplos começam com python tools/..., python agents/... ou python workflows/.... Esses caminhos pertencem à raiz original da fonte Quarto. No ZIP público, estão em laboratorio/codigo/tools/..., laboratorio/codigo/agents/... e laboratorio/codigo/workflows/.... O executor já resolve essas diferenças e gera seus próprios arquivos fictícios.

Quais capítulos são afetados?

Principalmente 9–14 e 16–21, que trazem comandos ligados à estrutura do livro. O capítulo 4 apresenta código independente; o capítulo 8 mostra um modelo de skill e um instalador; o capítulo 15 pede comparação conceitual de frameworks, não um benchmark real.

Como interpretar o relatório

Abra resultado.json dentro da pasta de saída. Verifique etapas, codigo_observado, saida_esperada e criterio. Uma falha intencional pode ser esperada; PASS_LIMITED significa somente que o cenário didático cumpriu as condições locais. Os capítulos de investigação recebem NAO_VERIFICADO até observação humana.
