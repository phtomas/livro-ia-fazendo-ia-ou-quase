COMANDOS

Execute os exemplos sem complicação

Passo a passo para usar os exercícios Python do kit do leitor no Windows, Linux ou macOS.

PYTHON 3.11+

SEM INSTALAR GIT

1. Baixe e prepare os arquivos

No repositório do livro, selecione Code → Download ZIP e extraia-o. Abra um terminal na pasta extraída. É necessário Python 3.11 ou superior.

python --version
python laboratorio/kit-do-leitor/executar.py --listar

2. Experimente um capítulo

Informe o número do capítulo e uma pasta nova para os resultados. A pasta de saída deve ficar fora da pasta do projeto.

python laboratorio/kit-do-leitor/executar.py --capitulo 13 --saida ../ensaio-13

3. Execute todos os roteiros locais

python laboratorio/kit-do-leitor/executar.py --todos --saida ../ensaios-21

No Windows, py -3 pode substituir python. No Linux/macOS, experimente python3. Para repetir, escolha outra pasta de saída.

4. Leia os resultados

Abra resultado.json na pasta criada. Observe os campos etapas, codigo_observado, saida_esperada e criterio. PASS_LIMITED significa que o cenário didático passou, não que um serviço externo tenha sido testado.

5. Experimente ferramentas avulsas

Alguns capítulos mostram comandos curtos como python tools/.... Para executar diretamente com os arquivos baixados, use o prefixo laboratorio/codigo/: por exemplo, python laboratorio/codigo/tools/arquivos/copia_provada.py --help. O executor do kit também resolve os caminhos necessários.
