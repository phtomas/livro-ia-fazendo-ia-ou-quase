Comece sem programar

O capítulo 1 ensina a comparar revisões de texto. O capítulo 2 ajuda a escolher a menor ferramenta. O capítulo 3 ensina a definir os limites de um agente. Nenhum deles exige instalações: basta ler, experimentar e anotar o que observou.

Como usar os scripts no Windows

  1. Acesse o projeto no GitHub, clique em Code e Download ZIP. Extraia os arquivos. Não precisa instalar Git.
  2. Tenha o Python 3.11 ou mais recente. Abra o Terminal ou PowerShell na pasta do projeto e confira python --version (no Windows também pode ser py --version).
  3. Copie este exemplo do capítulo 4, execute e abra a pasta de evidências criada fora do projeto.
python laboratorio/kit-do-leitor/executar.py --capitulo 4 --saida ../ensaio-cap04

Para listar as atividades, use python laboratorio/kit-do-leitor/executar.py --listar. Para todas, use python laboratorio/kit-do-leitor/executar.py --todos --saida ../ensaios-21. Um novo ensaio precisa de uma nova pasta de saída.

Como interpretar o resultado

PASS_LIMITED significa que um exemplo local passou nos critérios previstos, não que uma plataforma de IA foi validada. NÃO VERIFICADO identifica atividades que exigem observação humana. Alguns testes devem falhar de propósito para demonstrar bloqueios de segurança.

TRABALHE COM DADOS FICTÍCIOSNão use documentos de clientes, senhas, tokens nem arquivos importantes. Os exemplos não autorizam alterações em documentos reais nem ações fora do ambiente de teste.

O que já foi comprovado?

A suíte de testes locais passou no GitHub Actions em 16/11/2026, com dados sintéticos. Isso não comprova ativação das skills nos serviços de IA. Leia o quadro de evidências e gates editoriais.
