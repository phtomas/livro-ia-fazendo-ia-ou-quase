# Laboratório do leitor

## Preparação

1. Crie uma pasta descartável chamada `laboratorio-ia` em seu computador.
2. Nela, crie `entrada`, `saida` e `evidencias`.
3. Use apenas arquivos fictícios e anote versões das ferramentas.
4. Leia o código antes de executá-lo e não coloque credenciais em nenhum arquivo de exemplo.
5. Registre a saída e classifique PASS, FAIL ou NÃO VERIFICADO. Não confunda execução com prova.
