1. Objetivo

Executar um plano de leitura e impedir outro que tenta publicar.

2. Na prática com a IA / ferramenta

Use os planos sintéticos criados pelo executor; compare estados PASS_LIMITED e HALTED_POLICY.

O prompt integral, as restrições e o exercício editorial original estão na página pública do capítulo. Execute a consulta apenas se desejar e tiver acesso ao serviço; guarde a resposta literal.

3. Experimento independente do leitor

Projete quem tomou cada decisão e quais paradas exigem intervenção.

4. Arquivos e instruções

agents/ciclo_supervisionado.py + politica_orquestrador.py; dados fictícios.

Na pasta principal do repositório, usando Python 3.11+, execute:

EXEMPLO sh
python laboratorio/kit-do-leitor/executar.py --capitulo 11 --saida ../evidencias-cap11

Este capítulo possui ensaio Python offline com dados sintéticos. O comando produz resultado.json, relatórios e logs. PASS_LIMITED indica que apenas as saídas e condições especificadas foram exercitadas; não é aprovação integral da tarefa.

5. O que conta como prova

Códigos esperados 0/2; não há escolha de ações por LLM nem identidade de aprovador.

Não utilizar dados pessoais, tokens, documentos de clientes ou arquivos valiosos. Faça os exercícios apenas com os arquivos de exemplo ou cópias descartáveis.

Nada é “funcionou” sem prova. Use dados fictícios e confira os resultados.
