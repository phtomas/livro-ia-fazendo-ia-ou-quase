Arquitetura funcional de um agente de IA

Da intenção humana à ação verificável. Este esquema é uma interpretação didática original para o livro IA fazendo IA — ou quase; as tecnologias indicadas são exemplos, não uma lista obrigatória de componentes.

Atenção: LLM não é o agente inteiro. MCP é protocolo, RAG é abordagem de recuperação, Redis e PostgreSQL são infraestrutura e frameworks são escolhas de implementação. Os controles de segurança devem atravessar toda a execução.
